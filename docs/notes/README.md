# Notes

Working notes, learning logs and open questions. Decisions that stick go to [../adr](../adr).

## Format

Name each note `NNNN-kebab-topic.md` and keep its two parts separate:

```markdown
# NNNN: Topic

## In my words
3-5 lines from memory, written before pasting anything.
**My open question:** ...

## Reference (AI, checked against the docs)
The pasted explanation, for when I forget.
```

To revise, answer from memory first, then check the Reference.
